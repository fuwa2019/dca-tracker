# 2026-09-29 exposure layout release

Scope: private `/exposure` frontend only. The owner reviewed the local C
implementation and authorized commit and production release. No database,
Worker, calculation, public-share or dependency changes; no private-data reads.

## Behavior

- The largest stock fills the bar track; displayed percentages remain actual
  weights of total NAV. The 18px minimum bar width is removed.
- Bar grouping measures the actual track width. Stocks whose relative bar would
  be under 24px move to a two-column numeric list. It also caps the bar list
  at six stocks on mobile or eight on desktop. Equal-weight stocks stay in the
  same group; grouping updates with viewport and holdings changes.
- Each bar or numeric row has a native disclosure with the contributing sources
  as percentages of total NAV. There is no manual grouping control.
- A compact largest-stock and coverage summary replaces four separate cards.
  The existing top-14 scope is retained, with other decomposed exposure stated
  separately. Empty-stock portfolios show an explanatory message.
- Existing source colors, refresh behavior, data warnings and snapshot dates
  are preserved.

  offline demo dist is not uploaded.
- Offline browser inspection: desktop showed four bars and ten numeric rows;
  390px mobile showed three bars and eleven numeric rows. A source disclosure
  expanded correctly, and 390px and 320px views had no horizontal overflow.

  not installed. The accessibility-tree audit passed 26 route/viewport views.
  These probes use the offline demo; logged-in cloud routes and real assistive
  technology are not covered.
