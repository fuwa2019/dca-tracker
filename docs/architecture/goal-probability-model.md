# 目标概率规划模型

/settings/goal 的“概率规划”使用 2026-09-05 QQQM 研究包中的公开月度实际对数收益快照（1999-04 至 2026-07，共 326 个观测月）。2025-10/11 的 CPI 缺口保留为区块边界，不跨缺口拼接收益。

## 计算契约

- 每条路径先抽取五个基本面情景及其参数扰动，再用“80% 基本面漂移 + 20% 历史对数漂移”生成月度实际收益。
- 历史扰动使用 6、12、24、36 个月平稳区块抽样，每种区块长度占四分之一的路径；区块不会跨历史缺口。
- QQQM 年费 0.15% 已在月度漂移中扣除一次；结果为美元今天购买力、税前。
- 财富递推在每个月先应用收益，再加入月末定投；首次达到目标的月份会被记录，后续路径不再重复计入。
- 40 年之外的路径保留为右删失，因此 P90 等分位不会只对成功路径计算。

报告离线复现使用 50,000 条路径；浏览器交互使用固定种子和 4,000 条路径，以保持设置表单响应。结果是研究假设下的条件预测，不是保证收益、置信区间或退休提款安全率。

## 应用边界

应用读取账本当前持仓市值加现金作为起点，读取“目标金额”和“月定投”表单值实时计算；概率结果不保存到数据库，也不改变原有的总览单一路径参数和已实现收益。当前界面固定采用今天购买力不变的月定投、USD、无个人税务模型。

研究引擎是全仓 QQQM 等效模型。混合资产组合仍会显示结果，但结果仅是 QQQM 风险暴露的规划压力估算，不代表混合组合的精确预测；没有实时 QQQM 行情或持仓行情不完整时，界面不会生成结果。

压力情景沿用研究中的受控顺序实验：失去的十年、早期互联网泡沫、早期 2008 危机、15 年内估值回落到 PE20，以及前 20 年持续 AI 繁荣。它们用于检验顺序和假设敏感性，不赋予可验证的发生概率。
